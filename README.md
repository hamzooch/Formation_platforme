# DigitechPro

Monorepo scaffold for a modern e-learning platform.

## Structure
- `frontend/` Next.js + React + TypeScript + Tailwind CSS
- `backend/` NestJS REST API + Prisma (PostgreSQL)
- `docs/` Architecture, API, and data model references

## Quick Start (local dev)
> This scaffold includes minimal code stubs only. Initialize dependencies with your preferred tooling.

### Frontend
- `frontend/` is a Next.js App Router layout.

### Backend
- `backend/` is a NestJS structure with modules and REST endpoints.
- `backend/prisma/schema.prisma` defines the core data model.

## Next steps
1. Initialize package managers (pnpm/npm) in `frontend/` and `backend/`.
2. Install dependencies (Next.js, Tailwind, NestJS, Prisma).
3. Run DB migrations and seed data.
4. Implement auth and RBAC guards.
